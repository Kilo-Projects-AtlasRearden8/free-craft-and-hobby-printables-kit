## Quick Start (Three Ways to Use)

### Option 1: Print and fill by hand (fastest)

1. Open any `.html` file in your web browser (Chrome, Firefox, Safari, Edge).
2. Press **Ctrl + P** (Windows/Linux) or **Cmd + P** (Mac) to print.
3. In the print dialog, choose **Print to PDF** or your printer. Set margins to "Minimum" or "None" if available.
4. Fill in the blanks with a pen or pencil.

### Option 2: Fill in your browser, then print

1. Open any `.html` file in your browser.
2. Click into the text boxes, checkboxes, and dropdowns and type your details directly on screen.
3. Press **Ctrl + P** / **Cmd + P** to print or save as PDF. Your filled-in answers come with you.

### Option 3: Edit the Markdown source first

The `.md` files are plain-text source documents. Open them in any text editor (Notepad, TextEdit, VS Code, etc.), customize the wording or structure, then regenerate the HTML if you have [pandoc](https://pandoc.org/) installed:

```bash
pandoc project-planner.md -o project-planner.html --css=print.css --standalone
```

No pandoc? No problem — just use the `.html` files as-is.

## What's Inside Each Template

**Project Planner** — Plan a project from idea to finish. Includes project overview, materials needed, tools & notions, step-by-step milestones, a progress log, budget tracker, modifications & notes, and a completion checklist.

**Supply List** — Organize yarn, fabric, notions, tools, patterns, and shipping costs. Track what you have, what you need to buy, and where to shop. Includes a running subtotal and grand total.

**Pattern Tracker** — Record every detail of a pattern project: gauge, yardage, needle/hook size, row/round tracker, modifications, progress sessions, issues & solutions, blocking notes, and a star rating with review.

**Completion Log** — Look back at a full year of crafting. Track up to 20 finished projects, monthly hours, category totals, stash changes, skills learned, favorite projects, gifts given, and goals for next year.

## Features

- **Fillable forms** — Type directly in the browser before printing. No registration, no email, no account.
